# Grace Isitua — Services

## Service 1: Frontend Development
**Tagline**: Fast, accessible, and responsive web applications.

Grace builds modern, responsive, and user-friendly web interfaces using the latest frontend technologies. Every project is built for speed, accessibility, and long-term scalability.

**What's included:**
- React and Next.js web applications
- TypeScript-based codebases
- Tailwind CSS responsive design
- Component-driven architecture
- Core Web Vitals optimization
- Accessibility implementation (WCAG standards)
- SEO-ready markup

**Best for:** Startups, product teams, SaaS platforms, and businesses that need a fast, polished web presence.
